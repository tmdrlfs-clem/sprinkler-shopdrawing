Everything runs in your browser and nothing is uploaded. Each session starts clean — use Save work file to keep a job, and drop that file back here to carry on. A work file can also be dropped straight onto this window.

  1. Set the scale. If the drawing says 1:50 or 1:100 it is picked up automatically; otherwise click two ends of a known dimension.
  2. Measure anything with the length tool. It snaps to the drawing’s own lines, corners and intersections.
  3. Trace a room with the room tool. The area is calculated as you close the polygon.
  4. Give the room a hazard class and a head grid is laid out for you, ready to nudge by hand.
